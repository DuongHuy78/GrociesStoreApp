# GrociesStoreApp

GrociesStoreApp là một ứng dụng di động quản lý và mua sắm thực phẩm, phát triển bằng Flutter. Ứng dụng giúp người dùng dễ dàng tìm kiếm, lựa chọn các mặt hàng tạp hóa, quản lý giỏ hàng và trải nghiệm mua sắm tiện lợi ngay trên điện thoại.

## Tính năng nổi bật

- **Khám phá sản phẩm**: Cung cấp danh sách các loại thực phẩm đa dạng như rau củ, trái cây, thịt cá, đồ uống, gia vị, thực phẩm đông lạnh,... với thông tin chi tiết và hình ảnh minh họa trực quan.
- **Tìm kiếm thông minh**: Thanh tìm kiếm giúp người dùng nhanh chóng tra cứu sản phẩm mong muốn.
- **Ưu đãi & Sản phẩm độc quyền**: Hiển thị danh sách các mặt hàng giảm giá, sản phẩm nổi bật và mặt hàng độc quyền.
- **Quản lý giỏ hàng**: Dễ dàng thêm, xóa, cập nhật các sản phẩm trong giỏ hàng của bạn.
- **Phân loại thực phẩm**: Hỗ trợ lọc sản phẩm theo nhóm (rau củ, ngũ cốc, hải sản, đồ uống...) giúp người dùng lựa chọn dễ dàng.
- **Trải nghiệm người dùng mượt mà**: Giao diện hiện đại, hỗ trợ chuyển đổi giữa các màn hình chính như Trang chủ, Khám phá, Giỏ hàng, Tài khoản cá nhân.

## Công nghệ sử dụng

- **Flutter**: Xây dựng giao diện người dùng đa nền tảng.
- **Bloc pattern**: Quản lý trạng thái hiệu quả cho các màn hình và tính năng chính.
- **Dart**: Ngôn ngữ lập trình chính cho dự án.

# GrociesStoreApp

GrociesStoreApp is a mobile application for grocery shopping, developed with Flutter. This app helps users easily search, select groceries, manage their shopping cart, and enjoy a seamless shopping experience right on their mobile device.

## Features

- **Product Discovery**: Browse a wide variety of grocery categories such as fruits & vegetables, meat & seafood, beverages, condiments, frozen foods, and more, all with detailed information and images.
- **Smart Search**: Quickly find your desired products with an intuitive search bar.
- **Exclusive Offers & Discounts**: View lists of discounted items, exclusive deals, and highlighted products.
- **Cart Management**: Effortlessly add, remove, and update items in your shopping cart.
- **Category Filtering**: Filter products by categories (fruits, grains, seafood, drinks, etc.) for easy selection.
- **Smooth User Experience**: Modern interface with smooth navigation between Home, Explore, Cart, and Account screens.

## Technologies Used

- **Flutter**: Cross-platform UI development.
- **Bloc pattern**: Efficient state management for main screens and features.
- **Dart**: Main programming language of the project.

## Getting Started

1. Clone the repository:
   ```
   git clone https://github.com/DuongHuy78/GrociesStoreApp.git
   ```
2. Install dependencies:
   ```
   flutter pub get
   ```
3. Run the application:
   ```
   flutter run
   ```
